# Session Recap

Short session recap so you know what you got done and what's dangling.

## Steps

### 1. Gather from Conversation Context

Do NOT make MCP calls or run commands. Infer everything from the
current conversation:

- Tasks completed or progressed
- Tickets worked on
- PRs opened, reviewed, or merged
- TODO items added or checked off
- Anything left unfinished or unresolved

### 2. Present

```
Session recap:

-- DONE ----------------
- <concise bullet per accomplishment>

-- LOOSE ENDS ----------
- <anything unfinished, uncommitted, or to pick up next>
```

Skip any empty section. If nothing is dangling, say so.

### 3. That's It

No follow-up prompts, no suggested next moves. Just the summary.
